Aviation Parts Intelligence & PDF Data Extraction

Independent demonstration. Synthetic data. Not employer work.

Extracting part numbers and associated data from numerical index sections of multiple PDF catalogues into one validated Excel output.

Problem statement

Part numbers sit in numerical index sections across many PDF documents. Manual copying is slow, inconsistent and hard to audit.

Business requirements

Capture part number, description and reference per entry; standardise formats; flag duplicates; produce one consolidated workbook with an exceptions list.

As-is process

Open each PDF, locate the numerical index, copy entries by hand into Excel, reconcile duplicates visually.

To-be process

Scripted or tool-assisted extraction of index pages, automated cleaning, rule-based duplicate and validation checks, reviewer sign-off on exceptions only.

Extraction methodology

Identify index page ranges, extract text by layout, parse line patterns, record source file and page for traceability. Scanned PDFs need OCR and a separate accuracy check.

Cleaning and standardisation

Trim whitespace, normalise separators and case, keep original value beside cleaned value.

Duplicate identification

Match on normalised part number; report count and source files for each repeated value.

Validation and exceptions

Rules: non-empty, expected character pattern, length range. Failures go to an Exceptions sheet with reason codes.

Consolidated Excel output

Sheets: Parts, Duplicates, Exceptions, Source Log. See assets/documents/synthetic_parts_index.csv.

Potential Power Automate implementation

Concept only: file arrives in a folder, flow runs extraction, writes rows to Excel, notifies a reviewer of exceptions.
