# Aviation BA & Supply Chain Analytics Portfolio
Static HTML/CSS/JS site, GitHub Pages ready. All demo data is synthetic.

## Deploy
1. Create a repo, upload the contents of this folder to the root.
2. Settings > Pages > Source: main branch, / (root).
3. Site goes live at https://USERNAME.github.io/REPO/.

## Update
- Replace every `[EDIT]` and `Brahm Deo` / `deobsoa@gmail.com` placeholder.
- Add `resume/resume.pdf`.
- Nav is defined in `js/main.js`. Project content lives in `projects/*/index.html` and README.md.
- Add a project: copy a project folder, edit, add a card on index.html and projects.html.

## Pre-publish checklist
- [ ] All placeholders replaced or removed
- [ ] resume.pdf present and downloads
- [ ] Every nav and project link works (click through all 11 pages)
- [ ] Checked at 360px, 768px, 1280px widths
- [ ] Keyboard-only navigation and skip link work
- [ ] No employer-confidential content or real data
- [ ] Skills listed match evidence (SQL/Python only with projects)
- [ ] Dark mode and reduced-motion look fine
